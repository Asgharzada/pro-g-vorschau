# Nur Abstimmungsstand

Diese statische Fassung diente der Abstimmung, bevor die Website auf WordPress
umgezogen ist. Sie wird nicht mehr gepflegt.

**Die Website steht auf <https://zacodantech.de>.**

Die Vorschau ist auf `noindex` gesetzt und per `robots.txt` gesperrt, damit sie
nicht mit der echten Domain um Suchtreffer konkurriert. Sobald die Website
oeffentlich ist, sollte dieses Repository auf privat gestellt oder GitHub Pages
darin abgeschaltet werden.
